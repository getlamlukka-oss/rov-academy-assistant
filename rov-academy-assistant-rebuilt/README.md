# RoV Academy AI Assistant — rebuilt
สร้างใหม่จาก App.tsx + types.ts รุ่นเก่าที่ผู้ใช้ให้มา เนื่องจาก Source ของเว็บออนไลน์ล่าสุดไม่มีให้ดึง

## Run
1. npm install
2. copy .env.example .env และใส่ GEMINI_API_KEY
3. เปิด terminal 1: npm run server
4. เปิด terminal 2: npm run dev

หมายเหตุ: Bridge จริงของ academy.rov.in.th ต้องติดตั้ง/เชื่อมแยกต่างหาก เว็บนี้ไม่ข้าม CAPTCHA และไม่เก็บรหัสผ่าน
